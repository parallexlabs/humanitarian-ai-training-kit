# Modèle imprimable de fiche de transparence

**Exemple de conception de formation. Ce document ne rend compte d'aucune formation donnée.** Une page par utilisation proposée de l'IA. Séquence d'animation de la séance 3 : voir la [fiche d'animation](../sessions/session-03-governance/run-sheet.md).

**Outil en ligne (optionnel) :** [ParalleX AI Transparency Card](https://parallexlabs.github.io/ai-transparency-card/) ([dépôt](https://github.com/parallexlabs/ai-transparency-card))

| Champ et consigne | Réponse |
|-------------------|---------|
| **Nom** — Titre court pour cette utilisation | |
| **Objectif** — Quelle tâche l'IA soutient et pourquoi | |
| **Outil et déploiement** — Produit, version si connue, lieu d'exécution | |
| **Niveau requis** — Niveau 1, 2 ou 3 (voir le [tableau croisé SAFE AI](ai-decision-guide.md#safe-ai-crosswalk)) | |
| **Décision (vert / ambre / rouge) et motifs** — Décision feu tricolore avec brève justification | |
| **Données concernées** — Types, sensibilité, conservation | |
| **Mesures de protection en place** — Approbations, vérification, examen humain | |
| **Mesures de protection manquantes** — Lacunes à combler avant une utilisation élargie | |
| **Rôle responsable** — Responsable nommé pour cette utilisation | |
| **Date du prochain examen** | |
| **Journal des changements** — Date et résumé des changements importants | |
| **Plan de participation 1** — Comment les personnes touchées sont informées de l'utilisation (canal, langue, moment) | |
| **Plan de participation 2** — Comment elles peuvent poser des questions ou déposer une plainte (mécanisme de rétroaction) | |
| **Plan de participation 3** — Comment elles sont consultées et comment leur contribution modifie l'utilisation | |
| **Plan de participation 4** — Comment elles reçoivent une réponse après une contribution ou une plainte | |

Les fiches rédigées pendant la formation portent uniquement sur des cas fictifs. Toute consultation réelle doit suivre le processus AAP de votre organisation.

## Exercice de la séance 3 (animation seulement; ne fait pas partie de la fiche imprimable)

Minutes 0 à 2 : l'animateur explique les champs et attribue le cas fictif déjà utilisé dans le bloc de décision. Minutes 2 à 12 : les binômes rédigent la fiche; inscrivez « inconnu — à vérifier » plutôt que d'inventer des renseignements et utilisez des rôles fictifs pour les responsables. Minutes 12 à 15 : deux binômes volontaires présentent un champ; les autres le remettent par écrit. Ce retour collectif fait partie des 15 minutes.
