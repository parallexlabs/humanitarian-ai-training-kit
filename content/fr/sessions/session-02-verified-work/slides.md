# Rappel

# Une consigne vague

« Résumez l'évaluation des besoins pour la réunion des donateurs. »

**Problèmes :** Pas de public, pas de fichier source, pas de format, pas de règle pour les données manquantes.

---

# Une consigne structurée

« Vous aidez un responsable de programme à rédiger une note interne.

**Tâche :** Résumer seulement les résultats de l'enquête.
**Public :** Équipe MEAL interne.
**Source :** Annexe S2 seulement. N'utilisez pas d'autres fichiers.
**Format :** 5 points, max 120 mots.
**Si des données manquent :** Écrire « Ne figure pas dans la source » au lieu de deviner. »

---

# Une meilleure consigne ne signifie pas sûr

| Bonne consigne | Toujours requis |
|----------------|-----------------|
| Tâche claire | Outil approuvé pour le type de données |
| Source nommée | Vérification de chaque chiffre |
| Règles de format | Approbation humaine avant usage externe |

Même grille pour tous.

---

# Méthode de vérification des sources

1. Lister chaque affirmation importante
2. La trouver dans la source autorisée
3. Marquer : fondée / non fondée / contredite
4. Décider : utiliser / examiner davantage / rejeter

# Note internationale

Les partenaires, les langues et la connectivité diffèrent.

Faible bande passante : partager les fichiers texte tôt.

La vérification compte davantage quand les sources arrivent tard ou fragmentées.
