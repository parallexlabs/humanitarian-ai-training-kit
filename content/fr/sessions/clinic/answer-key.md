# Modèles de réponse de l'animateur, clinique

## Questions d'approbation d'outil

**Modèle :** Ambre jusqu'à confirmation avec l'informatique/la vie privée. Action : courriel à l'approbateur avec description de la tâche et classification des données.

## « Est-ce correct d'utiliser ChatGPT pour...? »

**Modèle :** Dépend du type de données et de la politique de l'organisation. Ambre par défaut pour toute donnée personnelle ou opérationnelle sensible. La rédaction publique peut être verte avec vérification.

## Pression sur le rapport aux donateurs

**Modèle :** Rouge pour les statistiques non vérifiées. Action : approbation MEAL sur le tableau des sources.

## Enthousiasme pour la démo du fournisseur

**Modèle :** Ambre/rouge pour les achats. Action : charte + AIPD avant pilote.

## Débriefing

Pas de corrigé unique; l'animateur documente les thèmes pour le rapport de l'organisation hôte.
