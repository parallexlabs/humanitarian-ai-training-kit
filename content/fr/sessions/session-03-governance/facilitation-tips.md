# Conseils d'animation, séance 3

## Sujets sensibles

Les discussions de gouvernance peuvent faire émerger la peur de perdre son emploi ou l'embarras d'une utilisation passée d'outils. Ancrer dans les systèmes; les discussions ne reposent pas sur la culpabilité individuelle.

## Équité

Demander comment le statut migratoire, la langue, le handicap ou la documentation pourrait changer les résultats de l'IA. Le brief fictif devrait inciter aux vérifications par sous-groupe dans la charte.

## Participants en direction

Les inviter à nommer des voies d'approbation réalistes. Éviter qu'ils dominent le temps de parole.

## Faible bande passante

Le modèle de charte fonctionne hors ligne. Le bloc de contestation peut être asynchrone : le groupe A publie la décision; le groupe B publie la contestation écrite dans un forum.

## Transmission des matériels

S'assurer que l'organisation hôte reçoit les modèles de charte de pilote et les thèmes agrégés pour les communautés de pratique.
