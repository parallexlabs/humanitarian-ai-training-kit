# Technology and accessibility checklist

For hosting organizations and facilitators. Complete before Session 1.

## Platform and connectivity

- [ ] Session link, dial-in number, and passcode tested from a low-bandwidth connection
- [ ] Co-host assigned for chat, breakouts, timing, and accessibility requests
- [ ] Breakout rooms pre-assigned for expected attendance (see curriculum overview group sizing)
- [ ] Poll or form tool works without participant login where possible
- [ ] Plain-text case files sent by email before session (not live link dependent)

## Captioning plan

| Option | When to use | Check |
|--------|-------------|-------|
| Platform auto-captions | Default for many webinars | [ ] Facilitator knows how to enable; quality limitations explained |
| Professional CART or ASL | Requested by participant or org policy | [ ] Booked; join link sent to provider |
| Manual captioning | Auto-captions unavailable | [ ] Co-host types key terms in chat |

- [ ] Participants told how to request caption size or contrast adjustments
- [ ] Recordings, if any, include captions before reuse (default: no breakout recording)

## Synchronous low-bandwidth route

**Not the same as asynchronous text-only.** Participants stay in the live session.

- [ ] Phone dial-in available alongside data connection
- [ ] Facilitator repeats chat contributions aloud for audio-only participants
- [ ] Slides shared as PDF or plain text before session; no requirement to watch video
- [ ] Breakout alternative: plenary pairs or typed responses to co-host
- [ ] Worksheet submission via email or SMS to co-host during session if forms fail

## Asynchronous fallback (when live join is impossible)

- [ ] Worksheet due within 48 hours; debrief by email or short follow-up call
- [ ] Answer key sent after submission deadline, not before
- [ ] Participant offered clinic or 15-minute catch-up slot

## Visual and motor access

- [ ] Slide content available in HTML and PDF; diagrams have text equivalents on kit pages
- [ ] No information conveyed by colour alone (supported or contradicted uses words)
- [ ] Keyboard navigation works for HTML slide decks (arrow keys and buttons)
- [ ] Touch targets on kit website meet WCAG 2.2 target size (verified in build audit)

## Cognitive and language access

- [ ] Agenda sent in advance with plain-language summary
- [ ] French materials linked for all session documents
- [ ] Interpretation booked if live language differs from materials
- [ ] Extra time available on request for reading case text (does not extend 90-minute session; use pre-reading)

## Privacy and safeguarding technology

- [ ] Chat retention policy aligned with org rules; PII removal process defined
- [ ] No AI meeting assistants on participant audio without explicit consent
- [ ] Pre-submitted clinic questions stripped of identifiers before sharing with facilitator

## Verification before go-live

- [ ] Dry run with co-host including phone-only participant test
- [ ] axe audit on hosted mirror (if self-hosting kit HTML): 0 violations
- [ ] Participant accommodation requests closed or escalated with named owner

## Kit build quality (reference)

Published kit HTML passes axe WCAG 2.2 AA (0 violations). PDFs pass PDF/UA-1 validation. Prefer HTML for participants using screen readers.
