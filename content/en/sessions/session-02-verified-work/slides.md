# Recall

---

# A vague prompt

"Summarize the needs assessment for the donor meeting."

**Problems:** No audience, no source file, no format, no rule for missing data.

---

# A structured prompt

"You are helping a program officer draft an internal brief.

**Task:** Summarize survey findings only.
**Audience:** Internal MEAL team.
**Source:** Annex S2 only. Do not use other files.
**Format:** 5 bullet points, max 120 words.
**If data is missing:** Write 'Not in source' instead of guessing."

---

# Better prompt does not mean safe

| Good prompt | Still required |
|-------------|----------------|
| Clear task | Approved tool for data type |
| Named source | Verification of every number |
| Format rules | Human approval before external use |

---

# Role routes today

- **Program / MEAL:** Prompt + source check
- **Manager:** Should this task use AI?
- **Technical:** Tool and data controls

Same rubric for all.

---

# Source-check method

1. List each consequential claim
2. Find it in the authorized source
3. Mark: supported / unsupported / contradicted
4. Decide: use / further review / reject
