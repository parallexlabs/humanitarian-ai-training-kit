# Session 2 learning objectives

**Level 2: Verified work by role** | 90 minutes

## By the end of this session, participants will be able to:

1. **Recall** one rule from Session 1 and apply it to a new case.
2. **Compare** a vague prompt with a structured prompt that names task, audience, sources, format, and missing-fact rules.
3. **Improve** a prompt for a synthetic program/MEAL task or evaluate whether a task belongs in an AI workflow (manager route).
4. **Check** a supplied AI output against its source, correct unsupported claims, and choose use, further review, or rejection.
5. **Explain** one correction and one human approval point to peers.
6. **Write** a one-line action plan for verification at work.

## Role-specific routes

| Role | Emphasis in exercise |
|------|---------------------|
| Program / MEAL | Prompt improvement + source check (Cases 2 or 3) |
| Manager | Workflow fit: should this task use AI at all? |
| Technical | Tool/vendor controls from checklist |

All routes use the same rubric and seven-step screen.
