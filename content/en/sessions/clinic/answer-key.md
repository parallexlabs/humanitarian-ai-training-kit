# Clinic facilitator answer patterns

## Tool approval questions

**Pattern:** Amber until confirmed with IT/privacy. Action: email approver with task description and data classification.

## "Is it OK to use ChatGPT for...?"

**Pattern:** Depends on data type and org policy. Default amber for any personal or sensitive operational data. Public drafting may be green with verification.

## Donor report pressure

**Pattern:** Red for unverified stats. Action: MEAL sign-off on source table.

## Vendor demo enthusiasm

**Pattern:** Amber/red for procurement. Action: charter + DPIA before pilot.

## Debrief

No single answer key; facilitator documents themes for hosting organization report.
