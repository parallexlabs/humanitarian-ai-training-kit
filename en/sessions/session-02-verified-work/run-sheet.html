Session 2 facilitator run sheet

Verified work by role | 90 minutes | Level 2

Time Activity Facilitator actions Materials
0:00 to 0:10 Recall One rule from Session 1; link to verification Slide 2
0:10 to 0:25 Teach: prompts Vague vs structured prompt side by side Slides 3 to 6
0:25 to 0:45 Pairs: prompt lab Program pairs improve prompt; managers decide workflow fit; technical reviews tool row Worksheet Part A
0:45 to 0:48 Screen break 3 minutes
0:48 to 1:10 Groups: source check Check AI output vs source; mark use / review / reject Case 2 or 3; Worksheet Part B
1:10 to 1:25 Debrief Each group: one correction + one approval point Answer key
1:25 to 1:30 Close Recall + action plan Slide 12

International option

For mixed connectivity context, use Case 5 (chatbot) with partner and multilingual notes in debrief. Text-only worksheets; no live AI required.
