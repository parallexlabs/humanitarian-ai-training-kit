Optional live-tool lab route (Session 2)

Default remains no-account: pre-supplied AI outputs on the worksheet. Use this route only when all conditions below are met.

Approval conditions

Safety rules (read aloud before opening the tool)

  1. Open only the organization-approved tool URL. Do not use personal accounts on consumer tools unless policy explicitly allows.
  2. Enter only the synthetic prompt and source text from this page.
  3. Do not paste email threads, beneficiary lists, case numbers, or partner documents.
  4. Delete or clear session history after the exercise if your org policy requires it.
  5. Stop immediately if the tool outputs unexpected personal data or offensive content; report to IT per org policy.
  6. Classroom output is not approved for operational use.

Synthetic data pack

Source S2 excerpt (same as worksheet): “412 households surveyed in 6 villages. 31% reported inadequate water access in dry season. Survey does not estimate district-wide prevalence.”

Permitted prompt (participants may improve structure, not add data):

“Summarize the water access finding from Source S2 for an internal program team. Use only S2. If prevalence for the whole district is not in S2, write ‘not established.’”

Lab timing (replaces 0:25 to 0:45 prompt lab only)

Time Action
0:25 to 0:28 Safety rules; confirm synthetic data only
0:28 to 0:40 Pairs run permitted prompt in approved tool
0:40 to 0:45 Pairs complete source-check table on their live output vs S2

Continue run sheet from 0:48 (screen break and group source check) unchanged, or merge live output into Part B discussion.

Expected learning differences

Participants may see live hallucinations (e.g., invented district prevalence). Debrief this as a verification lesson, not a prompt failure alone.

When not to use this route

  • No org-approved tool
  • Mixed approval status in the room without separate breakouts
  • Unable to enforce synthetic-data-only rule
  • Low-bandwidth session without stable connectivity (use pre-supplied route)

Reporting

Note in hosting org summary: “Session 2 live-tool lab used: yes/no.” Do not collect tool transcripts containing user edits beyond rubric scoring.
