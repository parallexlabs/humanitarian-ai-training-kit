Une consigne structurée

« Vous aidez un responsable de programme à rédiger une note interne.

Tâche : Résumer seulement les résultats de l’enquête. Public : Équipe MEAL interne. Source : Annexe S2 seulement. N’utilisez pas d’autres fichiers. Format : 5 points, max 120 mots. Si des données manquent : Écrire « Ne figure pas dans la source » au lieu de deviner. »

Slide 8 of 13

Méthode de vérification des sources

  1. Lister chaque affirmation importante
  2. La trouver dans la source autorisée
  3. Marquer : fondée / non fondée / contredite
  4. Décider : utiliser / examiner davantage / rejeter

Note internationale

Les partenaires, les langues et la connectivité diffèrent.

Faible bande passante : partager les fichiers texte tôt.

La vérification compte davantage quand les sources arrivent tard ou fragmentées.

Plan d’action

Une habitude de vérification pour cette semaine :

  • Colonne source dans chaque tableau de brouillon
  • Examen par une deuxième personne pour les chiffres
  • Vérifier les traductions pour les négations
